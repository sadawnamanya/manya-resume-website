# Manya Sadawna - Resume Website

A personal resume website built with HTML, CSS and JavaScript.

## Files
- `index.html` - page structure, content and JavaScript
- `style.css` - all styling, linked from `index.html` with `<link rel="stylesheet" href="style.css">`

## Run it
Open `index.html` in a browser, or publish the folder with GitHub Pages
(Settings > Pages > Deploy from a branch > main > / (root)).

Keep `index.html` and `style.css` in the same folder.

## Notes
- Fonts load from Google Fonts, so an internet connection is needed for them.
- The resume PDF is generated inside the page, so no separate PDF file is needed.
